# ADR-005: Dream and narrative assets use sandbox branches

- **Status:** Accepted (2026-07-13)

## Context

Dreamer / sandbox and Narrator assets generate speculative, high-temperature, creative
output. This must not contaminate canonical memory or be presented as fact or therapy.

## Decision

Dream / narrative generation runs in **sandbox branches** of the ledger, with typed
outputs (`synthetic_experience`, `dream_simulation`, `creative_artifact`). Fixed seed,
snapshot ID, and parameters are recorded for reproducibility. Output is never evidence.

## Consequences

- Creative annealing is not therapy unless clinically grounded.
- Sandbox branches can be discarded without affecting canonical memory.
- Narrator / personal-imagery work is exploratory, not factual.
