# Compositional coverage phenomenon atlas

Status: v1 audit completed; claim-first rejected as a global synthesis default.

## Purpose

The public claim-first gate repaired answer/claim consistency and missing-link
abstention, but its one permitted private transfer still compressed one part of a
multi-facet interaction protocol. This atlas localizes such omissions horizontally
before another synthesis intervention is designed.

It does not test retrieval: every question receives all and only its frozen sources.
It does not encode private wording or rerun private Q07.

## Frozen phenomena

| Pair | Phenomenon | Preserved distinction |
|---|---|---|
| `atlas-negative-constraint` | negative constraint | acknowledge first; delay repair |
| `atlas-temporal-contrast` | temporal contrast | former paper policy; current electronic policy |
| `atlas-mixed-polarity` | mixed polarity | included email; excluded telephone |
| `atlas-conditional-scope` | conditional scope | primary Friday; Saturday only on approval |
| `atlas-distributed-rationale` | distributed rationale | scheduling decision; separate reason |
| `atlas-acceptance-boundary` | acceptance boundary | accepted structure; rejected colour scheme |

Each pair has an easy explicit realization and a harder paraphrastic/discourse
realization with identical facet ids, roles and abstention Gold. Each positive answer
requires two independently cited facets and has one plausible prohibited collapse.

## Registered baseline audit

Run the already frozen baseline and claim-first operation without prompt changes on
all twelve cases. Score per phenomenon and difficulty:

- required-facet recall;
- exact two-facet completion;
- prohibited violations;
- citation correctness;
- schema errors;
- prompt/output tokens and latency.

The audit is diagnostic. It cannot promote a new representation or synthesis
operation. The dominant hard-minus-easy completion gap selects the next public design
target. Ties retain the simpler claim-first operation and require more fixtures rather
than post-hoc prompt tuning.

No density, embedding, tensor or UMR arm is justified by this audit alone.

## Result — atlas v1

| Metric | Baseline | Claim-first |
|---|---:|---:|
| Macro required-facet recall | 0.958 | 0.583 |
| Exact positive-case response rate | 1.000 | 0.583 |
| Mean unsupported-facet rate | 0.028 | 0.000 |
| Citation correctness | 1.000 | 1.000 |
| Prohibited violations | 0 | 0 |
| Prompt tokens | 2,008 | 2,524 |
| Output tokens | 856 | 412 |

Baseline omitted the former-paper facet in the hard temporal pair. In the easy
conditional pair, its structured claims preserved the correct approval condition but
its independently generated answer inverted that condition, counted as an unsupported
facet. This independently supports deterministic answer rendering.

Claim-first emitted no unsupported or prohibited relation, but over-abstained on five
positive cases. It failed both negative-constraint variants and the hard variants of
temporal contrast, conditional scope and distributed rationale. Mixed polarity and
acceptance boundary remained complete.

The three hard/easy completion gaps are tied. No phenomenon is selected post hoc.
Claim-first remains useful as a validated missing-link operation but is rejected as a
global default. A versioned public extension must add cases for the tied phenomena
before the next operation is chosen; v1 fixtures and results remain frozen.

## Registered v2 extension

V2 leaves every v1 case and result unchanged. It adds two pairs each for temporal
contrast, conditional scope and distributed rationale: pricing and badge-policy
changes; overflow-room and rollback conditions; route and archive-relocation reasons.

Selection is frozen before generation:

1. select a unique maximum count of easy-complete/hard-incomplete drops;
2. if tied, select a unique lowest mean hard required-facet recall;
3. if still tied, select nothing.

Only the existing baseline and claim-first arms are audited. V2 is localization, not
prompt tuning or an intervention gate.

## Result — v2 extension

| Metric | Baseline | Claim-first |
|---|---:|---:|
| Macro required-facet recall | 1.000 | 0.667 |
| Citation correctness | 1.000 | 1.000 |
| Unsupported-facet rate | 0.000 | 0.000 |
| Prompt tokens | 2,017 | 2,533 |
| Output tokens | 911 | 498 |

Claim-first completed all four temporal cases. It completed the easy conditional and
rationale cases but abstained on all four corresponding hard paraphrases. Conditional
scope and distributed rationale each produced two completion drops with hard recall
zero, so the preregistered tie-breaker still selects no individual phenomenon.

The shared error is relation normalization under paraphrase, not one relation type:
literal/easy causal and conditional statements pass, while semantically equivalent
relational wording triggers over-abstention. The next candidate must separate question
requirements, relation support and deterministic rendering. It must be gated on new
held-out public fixtures rather than rerun either atlas version.
