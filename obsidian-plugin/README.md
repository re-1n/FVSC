# FVSC Antourage — Obsidian plugin

Frontend для FVSC Antourage. Запускает локальный FastAPI-бэкенд (Python) и встраивает
визуализацию семантической карты + чат с LLM прямо во вкладку Obsidian.

## Зависимости

- Python 3.11+ с FVSC репо (см. `requirements.txt` в корне).
- Локальный Ollama с моделью, указанной в настройках плагина.
- Индекс текущих записей: создаётся локальным сервисом, обновляется кнопкой
  синхронизации в Antourage. Чистый сервис использует `.fvsc/cache.json` внутри vault.

## Сборка плагина

```bash
cd obsidian-plugin
npm install
npm run build      # → main.js
```

## Установка в vault

В директории `<vault>/.obsidian/plugins/` создать папку `fvsc-antourage/` и положить туда:

- `manifest.json`
- `main.js` (после сборки)
- `styles.css`

Включить плагин в Settings → Community plugins.

## Настройка

Settings → FVSC Antourage:

- **Python interpreter** — путь к `python.exe` в venv FVSC.
- **FVSC repo path** — путь к корню репозитория FVSC (cwd для uvicorn).
- **Port** — порт uvicorn, по умолчанию 8765.
- **LLM model** — Ollama-тег модели.
- **Auto-start backend** — поднимать ли FastAPI при загрузке плагина.

После настройки нажать «Restart backend» (или перезагрузить плагин).
Статус виден в status bar внизу: `● FVSC: up` зелёный = всё ок.

## Использование

- Команда **«Open Antourage»** или иконка в ribbon открывает Antourage.
- В диалоге можно задавать вопросы и возвращаться к сохранённым разговорам.
  Ответ появляется после завершения генерации; знакомые понятия становятся ссылками.
- **Карта понятий** открывает карту связей с физикой. Клик по узлу или ссылке
  из диалога открывает внутренний состав понятия. Автоматических переходов нет.
- В режиме **Внутри понятия** добавь составляющие вручную или выбери из связанных
  понятий. Клик по составляющей раскрывает следующий уровень. Цепочка вверху
  и **На уровень выше** позволяют вернуться. **Мои понятия** открывает сохранённые понятия.
- Тяни узел для перемещения, фон для сдвига карты; колесо и +/- меняют масштаб.
  **Пауза физики** останавливает движение, **Вместить** возвращает все узлы в кадр.
- Состав сохраняется в `.fvsc/containers.sqlite3`; исходные заметки не изменяются.
  Пустой контейнер означает, что состав ещё не описан.
