# Установка FVSC Antourage

FVSC Antourage — плагин для Obsidian, который строит карту смыслов твоих заметок и даёт говорить с ней. Всё работает локально на твоём компьютере, в сеть ничего не уходит.

## Что понадобится

- Obsidian (если ещё нет — скачать с https://obsidian.md)
- ~3 ГБ свободного места
- 15–20 минут на первую установку

---

## 1. Установить Python 3.10 или новее

Скачай с https://www.python.org/downloads/.

**Очень важно** на первом экране установщика поставить галочку **«Add Python to PATH»** (внизу окна). Без этого плагин не сможет найти Python автоматически.

---

## 2. Установить Ollama (для чата)

Если хочешь разговаривать с картой — скачай Ollama с https://ollama.com/download.

После установки открой консоль (Windows: cmd или PowerShell; Mac: Terminal) и выполни:

```
ollama pull qwen2.5:14b-instruct-q4_K_M
```

Это разовая загрузка модели ~9 ГБ. Без Ollama карта работает, но без чата.

---

## 3. Скачать FVSC

Скачай архив проекта и распакуй в удобное место — например в `Documents/FVSC` или `Desktop/FVSC`. Плагин ищет FVSC в стандартных папках автоматически.

---

## 4. Скачать тезаурус

Скачай файл `conceptnet_ru.json` (~150 МБ) и положи его в папку `FVSC/data/`. Тезаурус нужен для качественной карты — без него связи между концептами получаются грубее.

---

## 5. Установить зависимости (один раз)

Открой консоль в папке `FVSC` и выполни:

```
pip install -r requirements.txt
```

Подожди 2–5 минут пока скачаются нужные библиотеки.

---

## 6. Установить плагин в Obsidian

1. Открой папку своего vault'а в проводнике/Finder (там где лежат твои `.md` заметки).
2. Зайди в `.obsidian/plugins/`. Если этой папки нет — создай её.
3. Внутри создай папку `fvsc-antourage/`.
4. Скопируй туда три файла из `FVSC/obsidian-plugin/`:
   - `main.js`
   - `manifest.json`
   - `styles.css`
5. Открой Obsidian → Настройки → Community plugins → включи «FVSC Antourage».

---

## 7. Первый запуск

Плагин при загрузке сам найдёт Python и папку FVSC. Если нашёл — увидишь зелёный кружок **«● FVSC: up»** в статус-баре внизу.

Открой панель «Антураж» — иконка-вилка слева в Ribbon, или Ctrl/Cmd-P → «Open Antourage».

Если карты ещё нет, плагин предложит её построить — нажми **«Построить карту»**. На vault'е из ~700 файлов это займёт 2–3 минуты.

Готово!

---

## Если что-то не работает

### Красный кружок «● FVSC: failed» в статус-баре

Открой Настройки → FVSC Antourage. Поля «Путь к Python» и «Папка FVSC» должны быть заполнены. Если под ними написано «Не найдено автоматически — укажи путь вручную», выбери путь к python.exe и к папке FVSC через кнопку «Перезапустить» внизу настроек.

### Чат отвечает «Ollama не отвечает»

Запусти Ollama (приложение в системном трее). Если Ollama не установлена — её не обязательно ставить, карта работает и без чата.

### Карта не строится / зависла

Открой Консоль (Ctrl/Cmd-Shift-I → вкладка Console). Сообщения с префиксом `[fvsc-backend]` покажут, что именно пошло не так.

### Совсем непонятно

Открой issue на GitHub с приложенным скриншотом Консоли — постараюсь разобраться.
