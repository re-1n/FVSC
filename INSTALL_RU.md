# Установка FVSC Antourage

FVSC Antourage — исследовательский плагин для Obsidian, который строит карту ассоциаций из заметок и позволяет обсуждать её с локальной LLM. Текущие ограничения интерпретации описаны в [README](README.md). Обработка использует локальный backend и Ollama; для загрузки зависимостей и моделей нужен интернет.

## Что понадобится

- Obsidian (если ещё нет — скачать с https://obsidian.md)
- Node.js и npm для сборки плагина из исходников.
- Место для Python-зависимостей, карты и выбранной модели Ollama. Размер модели проверяй перед загрузкой; единая оценка в 3 ГБ здесь неприменима.

---

## 1. Установить Python 3.10 или новее

Скачай с https://www.python.org/downloads/.

На Windows включи **«Add Python to PATH»**, чтобы команды ниже находили Python. Плагин также проверяет стандартные пути установки; если поиск не сработает, интерпретатор можно указать вручную в настройках.

---

## 2. Установить Ollama (для чата)

Если хочешь разговаривать с картой — скачай Ollama с https://ollama.com/download.

После установки открой консоль (Windows: cmd или PowerShell; Mac: Terminal) и выполни:

```
ollama pull qwen2.5:14b-instruct-q4_K_M
```

Это модель из настроек по умолчанию, а не обязательный выбор для любого компьютера. Можно использовать другую установленную модель, указав её тег в настройках. Без Ollama карта работает, но без чата.

---

## 3. Скачать FVSC

Скачай архив проекта и распакуй в удобное место — например в `Documents/FVSC` или `Desktop/FVSC`. Плагин ищет FVSC в стандартных папках автоматически.

---

## 4. Проверить данные тезауруса

Файл `data/conceptnet_ru.json` уже включён в репозиторий (около 12.8 МБ в проверенной версии). Отдельная загрузка не нужна. Это внешний лексический prior, а не свидетельство о личных убеждениях; его пользу следует оценивать сравнением с вариантом без тезауруса.

---

## 5. Установить зависимости (один раз)

Открой консоль в папке `FVSC` и выполни:

```
python -m pip install -r requirements.txt
```

Используй тот же интерпретатор Python, который затем будет указан в настройках плагина. В системе, где команда называется `python3`, замени `python` на `python3`.

---

## 6. Установить плагин в Obsidian

Сначала собери `main.js`: готового файла нет в исходном дереве репозитория. Из папки `FVSC` выполни:

```bash
cd obsidian-plugin
npm install
npm run build
```

1. Открой папку своего vault'а в проводнике/Finder (там где лежат твои `.md` заметки).
2. Зайди в `.obsidian/plugins/`. Если этой папки нет — создай её.
3. Внутри создай папку `fvsc-antourage/`.
4. Скопируй туда три файла из `FVSC/obsidian-plugin/`:
   - `main.js`
   - `manifest.json`
   - `styles.css`
5. Открой Obsidian → Настройки → Community plugins → включи «FVSC Antourage».

---

## 7. Первый запуск

Плагин попробует найти Python и папку FVSC автоматически. Зелёный **«● FVSC: up»** в статус-баре означает, что backend запущен; качество карты этим не проверяется.

Открой панель «Антураж» — иконка-вилка слева в Ribbon, или Ctrl/Cmd-P → «Open Antourage».

Если карты ещё нет, плагин предложит её построить — нажми **«Построить карту»**. Время зависит от объёма заметок и компьютера.

Готово!

---

## Если что-то не работает

### Красный кружок «● FVSC: failed» в статус-баре

Открой Настройки → FVSC Antourage. Если автоматический поиск не сработал, введи полный путь к `python.exe` или `python` в поле «Путь к Python» и путь к корню репозитория в поле «Папка FVSC». Затем нажми «Перезапустить» внизу настроек.

### Чат отвечает «Ollama не отвечает»

Запусти Ollama (приложение в системном трее). Если Ollama не установлена — её не обязательно ставить, карта работает и без чата.

### Карта не строится / зависла

Открой Консоль (Ctrl/Cmd-Shift-I → вкладка Console). Сообщения с префиксом `[fvsc-backend]` покажут, что именно пошло не так.

### Совсем непонятно

Открой issue на GitHub с приложенным скриншотом Консоли — постараюсь разобраться.
